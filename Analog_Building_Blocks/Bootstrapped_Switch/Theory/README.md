# Theory of Bootstrapped Switching

This directory covers the detailed theoretical analysis, mathematical derivations, and physical limitations of conventional analog switches, alongside the operating principles of the bootstrapped switch:

1. **[Conventional Switch Limitation](conventional_switch_problem.md)**: Derivation of the signal-dependent on-resistance ($R_{on}$) and its consequences (distortion, attenuation).
2. **[Bootstrapping Concept](bootstrapping_concept.md)**: Conceptual introduction to the floating voltage source approach.
3. **[Operating Phases](operating_phases.md)**: Clock phase descriptions (Hold vs. Tracking phase).
4. **[Mathematical Equations](equations.md)**: Governing equations for resistance, gain, and overdrive parameters.
