# On-Resistance ($R_{on}$) Measurements

This document presents the test setup and measured values for the switch on-resistance ($R_{on}$) characterization:

## Resistance Test Setup
To measure the exact channel resistance of the sampling switch across the input voltage range:
- A constant DC current load of **$10\ \mu\text{A}$** was applied across the switch.
- The input voltage was swept across the entire dynamic range from **$0.4\text{ V}$ to $1.4\text{ V}$**.
- This current was chosen to produce a negligible voltage drop ($\approx 0.5\text{ mV}$) across the switch, ensuring the main transistor ($M_1$) operates deep in the triode region without perturbing standard circuit operation.

## Measured Values
The extreme resistance values extracted from the parametric sweep are:
- **Maximum Resistance ($R_{on,max}$)**: **$31.86\ \Omega$** (measured at the maximum input voltage, $V_{in} = 1.4\text{ V}$).
- **Minimum Resistance ($R_{on,min}$)**: **$28.54\ \Omega$** (measured at the minimum input voltage, $V_{in} = 0.4\text{ V}$).
